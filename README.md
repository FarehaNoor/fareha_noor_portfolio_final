## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload the contents of this folder (not the ZIP itself).
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and use the URL shown in Settings → Pages.
